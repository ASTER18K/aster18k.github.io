{%- comment -%} Per-post body fonts picked by engfont / jpfont / korfont in front matter. See _data/fonts.yml. Each picked font draws only its own script; everything else falls through to the body font. A plain font-family stack can't do that (CJK fonts also ship Latin, Korean fonts also ship kana, and the system font on macOS swallows Hangul if listed first), so the script below fetches Google's CSS for the family, renames it to post-, and clips every @font-face unicode-range to that script. {%- endcomment -%} {%- assign picked = "" -%} {%- assign stack = "" -%} {%- assign langs = "eng,jp,kor" | split: "," -%} {%- for lang in langs -%} {%- assign key = lang | append: "font" -%} {%- assign pick = page[key] -%} {%- assign font = site.data.fonts[lang][pick] -%} {%- if font -%} {%- capture spec -%}{{ font.family | replace: " ", "+" }}{% if font.axes %}:{{ font.axes }}{% endif %}{%- endcapture -%} {%- capture picked -%}{{ picked }}["{{ lang }}", {{ spec | jsonify }}, {{ font.size | default: "100%" | jsonify }}], {% endcapture -%} {%- capture stack -%}{{ stack }}"post-{{ lang }}", {% endcapture -%} {%- endif -%} {%- endfor -%} {%- if stack != "" %} {%- endif %}
